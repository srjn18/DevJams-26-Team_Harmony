Adversarial Hard-Rule Test Suite

Deterministic validation that negations, exact numbers, and critical constraints survive compression without loss.

Case 1: Dropped Negation Trap Deterministic Rule

"Constraint: DO NOT use MongoDB for this project under any circumstances."

Must never be filtered or paraphrased into an affirmative. The negation "DO NOT use MongoDB" must survive byte-for-byte.

Case 2: Exact Numbers & Units Number Preservation

"Timeout is set to 30s. Enterprise SLA is $999/mo with 30 calendar days refund window."

Exact numerical thresholds must survive compression rather than being rounded or approximated.

Case 3: Soft vs Hard Constraint Tagging Gate

"The API must remain stateless" vs "Ideally the API would be stateless"

"Must remain stateless" is pinned; "Ideally" is treated as soft preference and not over-pinned.

Case 4: Deduplication Trap Semantic Separation

"We use Postgres." vs "We're migrating off Postgres next quarter."

Must not merge conflicting temporal states despite high word similarity.

ContextFlow 6-Stage Pipeline Architecture

Sequential multi-tiered optimization guaranteeing coherence, resilience, and cost efficiency.

1

Stage 1: Tier 0 Deterministic Prep (<5ms, $0 Compute)

Performs semantic chunking, tags entities (`SYSTEM`, `PERSISTENT_CONSTRAINT`, `DOC`, `TOOL_OUTPUT`), and pins critical constraints and negations.

2

Stage 2: Cost-Aware Routing Decision

Evaluates marginal savings vs optimizer compute. Short-circuits tiny requests with `SKIP`, executes fast semantic filter with `LIGHT`, or full compression pipeline with `FULL`.

3

Stage 3: Tier 1 Semantic Relevance & Deduplication

Two-threshold separation: Looser cosine threshold ($\tau_{rel}=0.18$) filters irrelevant chunks; Stricter threshold ($\tau_{dedup}=0.85$) merges redundant passages.

4

Stage 4: Tier 2 Compression & Budget Knapsack (with Graceful Fallback)

Extractively compresses verbose body chunks while protecting pinned sections. If compression times out or throws, catches exception and falls back to Tier 1 without failing.

5

Stage 5: Coherence Assembly (Position Flow)

Reorders surviving chunks strictly by original sequence position (`#position`), placing System prompt at top and Constraints immediately before the query.

ContextFlow API Specification

Three distinct, unbundled middleware endpoints.

POST /analyze

Dry-run cost estimation & routing decision. No paid LLM calls or optimization execution.

curl -X POST http://127.0.0.1:8000/analyze \
  -H "Content-Type: application/json" \
  -d '{"query": "...", "context": "...", "token_budget": 250}'
POST /optimize

Executes the 6-stage optimization pipeline. Returns optimized context, token waterfall, and stage latencies (no LLM inference).

curl -X POST http://127.0.0.1:8000/optimize \
  -H "Content-Type: application/json" \
  -d '{"query": "...", "context": "...", "token_budget": 250}'
POST /optimize-and-answer

Demo convenience endpoint. Runs optimization, executes downstream LLM inference, quality evaluation, and cost comparison.

curl -X POST http://127.0.0.1:8000/optimize-and-answer \
  -H "Content-Type: application/json" \
  -d '{"query": "...", "context": "...", "token_budget": 250}'
